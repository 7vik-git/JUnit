📘 JUnit Testing Assignment
This repository contains solutions to a series of Java unit testing problems using JUnit 5. Each problem is implemented with a focus on clean code, proper exception handling, and thorough test coverage. The tasks cover a variety of common programming scenarios to practice and demonstrate unit testing skills.

✅ Topics Covered
- Banking transactions and balance validations

- String utilities (reverse, palindrome, case conversion)

- List operations (add, remove, size)

- Exception handling in arithmetic operations

- User registration with input validations

- Parameterized tests for even number detection

Each module includes:

- A main class with the business logic

- A corresponding JUnit test class to verify functionality and edge cases
